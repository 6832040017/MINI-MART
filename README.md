## 🚀 ฟีเจอร์เพิ่มเติม (Interactive Features)
* **Shopping Cart System (ระบบตะกร้าสินค้า):** สามารถกดเพิ่มสินค้าลงในตะกร้า คำนวณราคาสินค้ารวม ปรับลดจำนวน และทำการสั่งซื้อสินค้าแบบจำลองได้ทันที

* **ปุ่มเปิดแผนที่ Google Maps:** ลิงก์ตรงไปยังพิกัดจริงของแต่ละทำเลในจังหวัดร้อยเอ็ด
* **นาฬิกาดิจิทัลเรียลไทม์:** แสดงเวลาปัจจุบันบนแถบบนสุดของเว็บไซต์

## 🌐 การ Deploy ขึ้น GitHub Pages (PaaS)
1. สร้าง Repository ใหม่บน GitHub เช่น `mini-mart`
2. อัปโหลดไฟล์ `index.html` และ `README.md`
3. ไปที่แท็บ **Settings** > **Pages**
4. ในส่วน **Build and deployment** > Source เลือก `Deploy from a branch`
5. Branch เลือก `main` / `root` แล้วกด **Save**
6. เว็บไซต์จะออนไลน์ทันทีที่ URL: `https://<username>.github.io/<repository-name>/`
